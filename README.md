# Saltillo, cruce por cruce

Mapa interactivo de los accidentes de tránsito georreferenciados por INEGI (ATUS) en Saltillo, Coahuila, 2024 y 2025.

- `index.html`: el sitio (MapLibre GL + mapa base OpenFreeMap).
- `data/accidentes.geojson`: 1,177 accidentes (municipio 030).
- `data/zonas.json`: fichas de cruces clave.
- `img/*.webp`: capas de calor y de cambio (densidad de kernel, radio 400 m, ponderada por gravedad).

Para publicarlo: Settings → Pages → Deploy from a branch → `main` / root.
